# Open Tray

نسخه اولیه رابط وب بازی **Open Tray**.

- منوی اصلی فارسی و راست‌چین
- طراحی مستقل با الهام از لانچرهای بازی و تصویر مرجع
- کارت‌های لابی، بازی انفرادی، ساخت لابی، رنک و پیوستن به لابی
- ورود با نام بازیکن
- آماده برای اضافه‌کردن بازی‌ها و قابلیت‌های اصلی در مراحل بعد
