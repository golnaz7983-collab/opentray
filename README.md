# Open Tray

بازی استراتژی چندنفره تحت وب.

## نسخه فعلی

- ساخت لابی و تولید کد ۶ رقمی
- پیوستن مستقیم با کد لابی
- بازی آنلاین چندبازیکنه با Supabase Realtime
- چت زنده داخل لابی و بازی
- نقشه واقعی کشورهای جهان با حالت‌های جهان، آسیا و اروپا
- رنگ اختصاصی برای هر بازیکن
- اسپان تصادفی
- ربات با سه درجه سختی: آسان، متوسط، سخت
- حمله با انتخاب درصد نیرو
- فتح کشورها و تولید/مدیریت نیرو با سقف ظرفیت
- ساخت شهر برای افزایش ظرفیت نیرو
- ساخت لنگر و ارسال کشتی با انیمیشن
- طلا و تبادل دریایی بین بازیکن‌های دارای لنگر
- طراحی Canvas برای رندر سبک نقشه و کنترل‌های زنده
- رابط فارسی RTL و واکنش‌گرا

## نقشه

برای مرزهای کشورها از داده‌های Natural Earth که در بسته World Atlas/Visionscarto ارائه شده استفاده می‌شود.
